Trees act as a containers for your nodes and is responsible for managing the execution of the nodes.
Each tree should represent a sequence of actions that you want to execute.

---
## Creating Jungle Trees

To create a tree in your project, right-click in the Assets window and select `Create > Jungle Tree`.

This will create a new Jungle Tree asset in your project. Double-clicking the tree will open it in the editor.

---
## Using Jungle Trees

Starting and stopping a tree is as easy as calling the `Start()` and `Stop()` functions on the tree instance.

Jungle Trees can be referenced as serialized fields in your scripts.
This allows you to easily reference your trees in the inspector.

```csharp
using UnityEngine;
using Jungle;

public class PlayJungleTree : MonoBehaviour
{
    [SerializeField]
    private JungleTree jungleTree;

    private void Start()
    {
        jungleTree.Start();
    }
}
```

<br />_The current state of the Jungle Tree._

| Flag | State    | Description                                                               |
|------|----------|---------------------------------------------------------------------------|
| 0    | Ready    | Describes a tree that has never been run and is not currently running.    |
| 1    | Running  | Describes a tree that is currently running.                               |
| 0    | Finished | Describes a tree that is not currently running but has run at some point. |
