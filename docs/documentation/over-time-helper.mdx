The `OverTimeHelper` class provides functionality for calculating value transitions over time using various motion methods. This class can be used in different scripts, not just node scripts, and is part of the `Jungle.Extensions` namespace.

## Overview

The `OverTimeHelper` class includes functionalities for:
- Calculating float, Vector2, Vector3, Quaternion, and Color values over time
- Determining the progress of these values towards a target
- Enabling or disabling the calculations
- Choosing between different motion calculation methods

Motion calculation method.

### `IsDone`

```csharp

```

Returns true if the calculation is done or if the transition is not enabled.

### `Default`

```csharp

```

Gets the default `OverTimeHelper` instance with Lerp motion and a rate of 1.

### `OverTimeHelper`

```csharp
public OverTimeHelper(bool enabled, bool scaledTime, float rate, Motion method, float precision = 0.01f)
```

#### Parameters

- `enabled`: Whether the helper is enabled.
- `scaledTime`: Whether to use scaled delta time.

## Enumerations

### `Motion`

Represents the motion calculation methods.

- `Translate`: Uses `Mathf.MoveTowards` or `Vector3.MoveTowards`.
- `Lerp`: Uses `Mathf.Lerp` or `Vector3.Lerp`.
- `Slerp`: Uses `Quaternion.Slerp`.
- `SmoothDamp`: Uses `Mathf.SmoothDamp` or `Vector3.SmoothDamp`.

## Example

Here is an example of how to use the `OverTimeHelper` class to smoothly transition a `Vector3` value over time:

```csharp
using System;
using Jungle;
using Jungle.Extensions;
using UnityEngine;

[NodeProperties(
    Title = "Set Position",
    Description = "Sets the inputted transform's position."
)]
[IONode(
    InputPortName = "Set",
    OutputPortName = "Done",
    OutputPortType = typeof(Transform)
)]
public class SetPositionNode : IONode<Transform>
{
    [SerializeField]
    private Vector3 position;

    [SerializeField]
    private OverTimeHelper overTime = OverTimeHelper.Default;

    private Transform _transform;
    private Vector3 _originalPosition;

    protected override void OnStart(Transform transform)
    {
        _transform = transform;
        _originalPosition = _transform.position;
    }

    protected override void OnUpdate()
    {
        _transform.position = overTime.SetVector3OverTime(_transform.position, position);

        if (overTime.IsDone)
        {
            CallAndStop(_transform);
        }
    }

    public override float GetProgress()
    {
        return OverTimeHelper.GetVector3Progress(_transform.position, position, _originalPosition);
    }
}
```
