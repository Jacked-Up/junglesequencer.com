The `JungleTree` class is a container for storing and managing sequences of `JungleNode`s.
It includes helper methods for adding, removing, connecting, and disconnecting `JungleNode`s.

## Overview

The `JungleTree` class provides the following functionalities:
- Managing a list of nodes in the tree.
- Adding, removing, and updating nodes.
- Connecting and disconnecting nodes.
- Handling editor-specific functionalities.
- Managing error reports related to nodes.
