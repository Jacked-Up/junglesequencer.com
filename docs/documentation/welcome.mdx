## Contributing to the Docs

We welcome contributions to the Jungle documentation!
If you find a typo or want to add a new page, always feel free to submit a pull request!
Each page can be edited by clicking the **Edit this page** link at the bottom of each page.

Thank you for helping us make the Jungle's documentation better!

## JungleGPT

JungleGPT is a custom GPT model that can help you with all of your Jungle-related questions.
It can write code, help you troubleshoot, and answer any questions you may have about Jungle.

The customized model is available to ChatGPT Plus subscribers and available
**[here](https://chat.openai.com/g/g-OcQk2cjfh-junglegpt)**.

:::warning
The custom GPT model is still being tuned. Sometimes JungleGPT may generate misleading or incorrect responses.
:::
