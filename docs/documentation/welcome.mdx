## About the Developer 👋

Hey, my name is Jack Randolph!
I’ve been building Jungle solo since 2019, and it’s my passion project.
It started as a tool for an ambitious game I was making (which never came out) but turned into something way bigger.

I went all-in on Jungle's development in 2022 and released it in August 2024.
I’m still tweaking, updating, and making it better every day.
Thanks for checking it out!
