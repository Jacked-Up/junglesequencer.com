Welcome to the Jungle Sequencer documentation site!
Here, you will find documentation for all of Jungle's API and guides to help you get started.

#### About the Developer

My name is Jack Randolph, and I've been programming and designing Jungle solo since 2019.
Jungle is my passion project and I love working on it so much.
It was originally built to be an internal tool for my very ambitious game that never came out.
As I was developing the tool for my ambitious game, I realized just how much potential it.

I built the tool in the background for a few years until I finally went full-time on the project in 2022.
After another two years of hard work, I finally got around to releasing it in August 2024.

I'm still working on it to this day, continuing to update and tweak the tool to make it as best it can be.
