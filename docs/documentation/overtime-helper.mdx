The `OverTime` class provides functionality for calculating values over time using various motion methods.

## Overview

The `OverTime` class includes functionalities for:
- Calculating float, Vector2, Vector3, Quaternion, and Color values over time
- Determining the progress of these values towards a target
- Enabling or disabling the calculations
- Choosing between different motion calculation methods

---

## Properties

### `enabled`

`public bool enabled`

True if this Over Time Helper is enabled. Used only for the inspector.

### `scaledTime`

`[Tooltip("Set true if the motion calculations should use scaled delta time.")] public bool scaledTime`

Set true if the calculation should use scaled delta time.

### `rate`

`[Tooltip("Time scale rate.")] public float rate`

Time scale rate.

### `method`

`[Tooltip("Motion calculation method.")] public OverTime.Motion method`

Motion calculation method.

### `IsDone`

`public bool IsDone { get; }`

Returns true if the calculation is done.

### `Default`

`public static OverTime Default { get; }`

Gets the default `OverTime` instance with Lerp motion and a rate of 1.

- `scaledTime`: Whether to use scaled delta time.

## Enumerations

### `Motion`

Represents the motion calculation methods.

- `Translate`: Uses `Mathf.MoveTowards` or `Vector3.MoveTowards`.
- `Lerp`: Uses `Mathf.Lerp` or `Vector3.Lerp`.
- `Slerp`: Uses `Quaternion.Slerp`.
- `SmoothDamp`: Uses `Mathf.SmoothDamp` or `Vector3.SmoothDamp`.
