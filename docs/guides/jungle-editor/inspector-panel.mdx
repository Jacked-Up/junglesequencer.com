## Editing Nodes

To edit a node's properties, simply left-click on the node within the graph.

![Opening nodes in the inspector](https://cdn.junglesequencer.com/v1.1.0/guides/jungle-editor/node-inspector-opening-nodes.gif)

This will open the node's inspector where you can modify its properties.

![Editing nodes in the inspector](https://cdn.junglesequencer.com/v1.1.0/guides/jungle-editor/node-inspector-editing-nodes.gif)

---
## Renaming Nodes

You can rename a node using the text input field located at the top of the inspector interface.
The node's name does not need to be unique.

![Renaming nodes in the inspector](https://cdn.junglesequencer.com/v1.1.0/guides/jungle-editor/node-inspector-renaming-nodes.gif)

---
## Custom Inspectors

The node inspector supports custom inspectors, offering a powerful way to extend the functionality of your nodes.
Creating custom inspectors for nodes is similar to creating them for `MonoBehaviour` and `ScriptableObject`.
This allows for tailored interfaces that suit the specific needs of your nodes.

For a detailed guide on creating custom node inspectors, read more **[here](../node-features/custom-inspector)**.
