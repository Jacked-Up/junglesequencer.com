The node explorer is a structured and organized list of every node in your project.
Nodes are added automatically and can be categorized for better organization.

![Browsing the node explorer categories](https://cdn.junglesequencer.com/v1.0.x/guides/jungle-editor/node-explorer-browsing-the-categories.gif)

To organize nodes into custom categories, set the `Category` property of the `NodeProperties` attribute on your nodes.
This allows you to create a customized and easily navigable hierarchy within the node explorer.

:::info NODE PROPERTIES DOCUMENTATION
Read more about setting the `Category` property of the `NodeProperties` attribute **[here](../../../docs/node-properties#category)**.
:::

## Adding Nodes

The node explorer allows you to drag and drop a node into the graph.

![Jungle editor explorer](https://cdn.junglesequencer.com/v1.0.x/guides/jungle-editor/node-graph-adding-nodes-via-node-explorer.gif)

**To add a node via the Node Explorer:**
- Scroll through the Node Explorer to find the node you want to add.
You can also use the search bar at the top to quickly locate the desired node.
- Click and hold on the node you wish to add. Drag it from the Node Explorer into the graph view.
- Move the node to the desired position on the graph and release the mouse button.
